Code AST Analysis CLI is a robust CLI tool designed to analyze Python code using an Abstract Syntax Tree (AST) approach. It supports static code analysis, local caching of analysis results, and asynchronous API testing for live code validation. The tool is modular, with clear separation of concerns between the core engine, the CLI interface, and the testing suite. This structure ensures maintainability and ease of expansion. The code follows best practices, with well-documented functions and comprehensive test coverage using pytest.
